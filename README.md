# 🎬 Movie Ticket Booking Management

## Project Overview
Movie Ticket Booking Management is a Pega-based application developed as part of the National Internship Program (NIP). The application manages the end-to-end movie ticket booking process, including request submission, availability checking, cost calculation, booking confirmation, ticket processing, and customer notification.

## Platform
- Pega Platform
- Pega App Studio
- Pega Dev Studio
- Pega Academy

## Application Details
- Application Name: Movie Ticket Booking Management
- Case Type: Movie Ticket Request

## Case Lifecycle
The Movie Ticket Request case contains the following primary stages:

1. Request Submission
2. Availability Check
3. Cost Calculation
4. Booking Confirmation
5. Process Booking
6. Notify Customer

## Key Features
- Movie ticket request submission
- Movie and show information management
- Show availability checking
- Seat availability verification
- Automatic ticket cost calculation
- Booking review and confirmation
- Ticket booking processing
- Customer notification
- SLA configuration
- Decision-based booking processing

## Project Result
The primary Movie Ticket Request workflow was successfully configured and tested in Pega. A booking request can progress through the complete lifecycle from Request Submission to Notify Customer, with ticket cost calculation and booking details processed successfully.

## National Internship Program
This project was developed for the Pega National Internship Program (NIP).
